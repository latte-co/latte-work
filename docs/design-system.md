# Latte Work 全局界面规范

这份规范约束应用导航、对话、设置、弹窗和菜单。视觉方向是安静、紧凑的深色桌面工作台：正文优先，工具执行记录保持轻量，操作控件不抢阅读注意力。

默认设计变量在 `apps/desktop/src/tokens.css`；外观设置通过 `appearance.ts` 生成颜色和字体覆盖值。组件布局和状态规则在 `style.css`，外观编辑器样式在 `appearance.css`。

## 颜色与层次

默认深色主题采用中性黑灰：主画布 #111111、侧栏约 #1A1A1A、菜单约 #232323、输入区约 #282828。默认主操作为浅灰白，Material 预设仍保留蓝灰配色；已保存的自定义主题不自动覆盖。

| 角色 | Token | 用途 |
| --- | --- | --- |
| 主画布 | `--color-canvas` | 对话和设置内容背景 |
| 侧栏 | `--color-sidebar` | 项目导航、设置导航 |
| 面板 | `--color-surface` | 弹窗、设置分组 |
| 浮层 | `--color-elevated` | 右键菜单、下拉菜单 |
| 输入区 | `--color-input` / `--color-composer` | 表单输入与聊天输入 |
| 主要 / 次要 / 辅助文字 | `--color-text` / `--color-text-secondary` / `--color-text-muted` | 正文、标签、说明 |
| 分隔 / 控件 / 浮层边界 | `--color-border-subtle` / `--color-border` / `--color-border-strong` | 统一使用 1px 线 |
| 主操作 | `--color-action` / `--color-on-action` | 发送、表单确认使用中性黑白 |
| 停止 | `--color-stop` / `--color-on-stop` | 独立中性控制色、方形图标 |
| 强调 | `--color-primary` / `--color-on-primary` | 链接、外观调色控件 |
| 键盘焦点 | `--color-focus-background` | 中性透明背景，不增加描边 |
| 品牌 | `--color-brand` | Logo、少量品牌装饰 |
| 状态 | `--color-success` / `--color-warning` / `--color-danger` / `--color-unread` | 成功、等待、错误、未读 |

发送、弹窗和表单确认按钮使用中性操作色（`--color-action` / `--color-on-action`）：深色主题白底深字，浅色主题深底白字。停止使用独立中性控制色。悬停使用各自角色的颜色，禁用使用禁用色；主题强调色不改变这些操作按钮。

金色不用于通用按钮背景、默认选中框或输入焦点。状态色需配合文字或图标，不单靠颜色传达含义。禁用主按钮使用独立的背景和文字色，避免对整个按钮降低透明度后产生浑浊的金色。

浅色默认白色画布、菜单和输入区，浅灰侧栏与选中项，中性深色主操作；使用浅灰边界和低强度阴影分层，避免整块灰底。

## 字体与间距

- UI 使用系统字体栈；macOS 由系统字体和中文回退字体渲染。
- 聊天 Markdown 正文为 14px，一级标题 16px、二级标题 15px、其余标题 14px，以 600 字重区分；行高 1.65。表格为 13px，使用轻量横向分隔线，无竖线或外框；代码块为 13px。其他正文沿用 15px，UI 为 13px，表单标签为 12px，辅助信息最小为 11px。
- 分组标题为 16px，弹窗与设置标题为 20px。品牌和欢迎页可以有独立展示字号。
- UI 常规字重 400，选中项/强调 500，标题 600。不要通过全局加粗制造信息层级。
- 品牌名称统一写作 `Latte Work`，保持单行与轻重字重层次；使用紧凑的 16px 品牌行，侧栏不显示 PREVIEW 标签或底部标语。
- UI 行高 1.5；现有对话 Markdown 的阅读行高及标题层级独立保留。
- 间距使用 4、8、12、16、20、24、32px。弹窗内边距 24px；字段标签到输入框 8px；内容组之间 24px；按钮之间 8px。
- 正文、输入区和设置表单统一使用 `--content-width`（780px），对话两侧留白使用 `--content-gutter`；三栏可调尺寸、44px 标题栏和模型选择器的紧凑布局保留。光学对齐、品牌和旧布局尺寸允许少量例外；新增组件不另创一套尺度。

| --- | --- |

| 图标按钮 | 默认图标 16px；点击区域至少 28×28px；顶部按钮沿用 32×28px |

| 项目名称组合输入 | 高度至少 48px；图标和输入文字属于同一容器；由外层绘制唯一边框 |
| 菜单项 | 高度至少 36px；上下 8px、左右 12px 内边距；圆角 6px |
| 菜单浮层 | 圆角 12px；统一浮层色、边框和阴影；表单菜单左对齐，靠右的工具栏菜单右对齐，避免越出窗口 |

## 交互状态

- 默认：用结构、文字和细边框建立层次。
- 悬停：浅色透明底，不改变尺寸和布局。
- 选中：统一选中背景，和悬停、键盘焦点区分。
- 点击和聚焦：全局保持原有边框宽度、颜色和圆角；禁止新增 outline、焦点阴影或高亮描边，包括组合输入的 focus-within 状态。
- 键盘操作：按钮、选择器、summary 和可聚焦输出区使用中性透明背景提示焦点，保留原有底色和文字对比；菜单保留高亮项。文本输入通过光标和选区提示焦点，不改变输入容器边框。
- 禁用：使用可读的禁用文字与按钮底色，不对复合控件叠加 opacity；图标与文字同步，不得留下正常悬停反馈。
- 错误：明确显示原因；等待/加载状态提供文字或旋转图标；不改变控件占位。
- 动效：常规颜色过渡 150ms；尊重系统减少动态效果设置。
- 侧栏开关：展开时位于侧栏顶栏右端，靠近会话区；收起时位于主顶栏左端，旁边保留新对话按钮。两种状态使用同一 16px 图标与 32 × 28px 点击区域，垂直居中于 44px 顶栏。
- 侧栏分组：标题和紧邻文字的 14px 箭头组成同一按钮，点击区域高度至少 28px；向右表示收起、向下表示展开。置顶与项目独立记住状态，标题旁的添加操作独立响应；收起不改变当前会话或项目归属。
- 置顶只用于会话，项目使用文件夹图标和项目列表原始顺序，不提供项目置顶菜单。
- 侧栏导航：“新任务”为 36px 高的无底色菜单项，只有悬停和键盘焦点反馈，不使用卡片边框。“新任务、置顶、项目”统一为 13px；分组标题行高 32px，上下间距分别为 8px / 4px；收起后不保留列表占位。
- 项目和任务采用紧凑的单行列表，项目行高 31px，任务行高 30px。项目行不显示常驻展开箭头，文件夹图标随展开或收起切换；点击项目行只展开或折叠其任务，不离开当前对话。点击任务才打开对应对话。任务缩进，不绘制树形竖线或常驻状态点。
- 项目行不使用选中背景，仅保留悬停和键盘焦点反馈；当前对话仍使用选中背景。
- 项目和对话行支持右键、键盘菜单键 / Shift+F10 及省略号按钮打开操作。项目行悬停或获得键盘焦点时显示更多操作与新任务；对话行显示更多操作、置顶与归档。新任务按钮打开空白任务并选中该项目及其所属主机。远程项目显示主机名及文件夹上的远程标记；项目收起且有运行中任务时显示动态省略号，等待确认时显示暂停图标。触屏环境始终显示操作按钮。
- 对话执行中显示横向动态省略号，等待确认显示暂停图标；完成但未读显示蓝色实心圆点，读取后清除。状态指示与操作共用行右侧空间：默认显示状态，悬停、焦点在行内或菜单打开时隐藏状态并显示操作，离开且菜单关闭后恢复；触屏始终显示操作。运行和等待确认的对话禁用快捷归档，须先停止；减少动态效果设置下省略号保持静态。
- 新任务先打开未保存的空白会话，首次提交非空内容时才创建持久会话。重复新建、列表刷新、离开页面或关闭窗口均不保存未提交的空任务；切换会话后，迟到的提交响应不能抢回当前页面。
- 新任务的输入区提供可搜索的项目选择器。收起时本机项目仅显示文件夹、项目名和展开箭头；远程项目追加次要文字 `SSH · 主机名`，不再叠加电脑或地球图标。悬停与无障碍描述保留主机和完整路径，展开列表明确标注「本机」或 `SSH · 主机名`。切换项目时保留未发送文本，恢复所选主机与 Agent 上次手动选择的模型和思考强度，并连接所选项目的主机；首次发送只向该主机创建任务。已有任务的项目归属不可通过选择器更改。
- 项目选择器仅悬停或键盘当前项使用高亮背景，背景随当前项移动；已选项目保留勾选，不额外占用一块背景。打开列表时键盘当前项从已选项目开始。

## 组件维护约定

1. 新页面复用现有按钮、表单、Select、弹窗和菜单规则，先查 token，再决定是否确实需要新增变量。
2. 组合控件必须明确谁负责边框、焦点和圆角。外层负责时，内层输入需要显式清除背景、边框、圆角和外边距，且选择器优先级足以覆盖通用表单规则。
3. 不在文件末尾不断叠加覆盖规则，也不以 `!important` 修补普通按钮/表单颜色冲突。
4. 16px 图标与点击面积是两个概念；不能通过缩小点击区域让图标显得紧凑。
5. 显示文本变长时优先截断或换行；保留 tooltip/说明，不能挤掉关闭、发送和侧栏按钮。

## 验收

修改公共样式后至少检查创建项目、设置表单、会话右键菜单、模型选择及聊天输入；对照默认、聚焦、悬停、禁用、选中状态。用真实桌面窗口检查中文排版、圆角、Mac 窗口控制区和键盘焦点。构建检查与真实桌面验证分别记录，未验证的状态不能宣称通过。

## 模型与思考强度菜单

输入区使用一个「模型名 + 思考档位」文字选择器与单个展开箭头，档位为次要文字。
主菜单列出模型，底部独立的 `Effort` 入口打开二级菜单，勾选当前档位。
模型没有自定义名称时保留原生 ID；有自定义名称时，菜单主文字显示该名称，右侧以浅灰色
和较小字号显示 Claude 别名，输入框按钮只显示自定义名称。选择值始终保持原生 ID。
Agent 档位保留原生英文值，不翻译或改写大小写；未覆盖档位显示「跟随 Agent」，
默认模型显示 `default`。模型和强度的手动选择按主机 / Agent 保存在本机，新任务、跨项目和重启后恢复；已有会话优先使用自己的参数。选择跟随 Agent 时不注入思考强度参数或环境变量，由 Agent 读取自己的配置。模型能力刷新导致的临时强度清除不会覆盖记忆。不支持调整时禁用二级入口，触发器省略档位。
每个模型行和档位行右侧固定预留 15px 勾选图标位置，未选中时隐藏图标但保留空间，
选中状态不得挤动名称和灰色别名。
主菜单宽 200px，档位子菜单宽 140px，长模型名截断并通过 tooltip 展示完整值。
菜单使用 36px 单行选项，主列表独立滚动、底部入口固定；子菜单优先在左侧展开，
空间不足时换边并约束在窗口内。上下键移动、Enter 选择，左右键进入/返回子菜单，
Escape 逐层关闭，点击外部关闭整个选择器。

## 自定义外观

设置采用通高双栏布局，内容画布与侧栏延伸到窗口顶端，不设置横贯页面的返回栏。
返回入口位于左侧导航的设置标题下方、分类列表之前；顶部保留透明的 44px 窗口拖动区域，正文通过内边距避开。

设置中的「外观」提供系统 / 浅色 / 深色模式；系统模式监听系统偏好变化。
浅色和深色各自保存配色、字体、字重、侧边栏透明效果和层次对比度。
设置默认即时应用，编辑非当前主题时只更新预览，不影响当前工作台。
UI、正文与代码分别使用 `--font-ui`、`--font-content`、`--font-code`；终端同步
代码字体和颜色，不重建终端或重放输入。字体使用本地字体栈，缺失时使用备用字体。
半透明侧边栏是应用内部的混色和模糊效果，不代表系统桌面透视或 macOS vibrancy。
对比度滑块调节面板和分隔线与背景的层次，保留用户指定的前景/背景；低文字对比度会提示。

`appearance.ts` 从受约束的颜色、字体枚举生成现有语义 tokens，避免组件保留固定深色。
外观仅存于 WebView 的 `latte-work.appearance.v1` 本地存储，不发送到主机。
主题 JSON 包含 `version: 1`、模式和两套完整配置；导入上限 32 KB，先验证所有字段，
再一次应用。错误输入不会覆盖当前配置；存储失败明确提示，损坏或未知版本回退默认，
且不自动覆盖原数据。恢复默认仅作用于正在编辑的主题。只保留预设选择器前的「导入 / 复制主题」入口；导入直接选择 JSON 文件，校验通过后一次应用。复制将完整配置写入系统剪贴板；失败时就地报错，不展开额外文本面板。格式与示例见 [主题 JSON](themes.md)。

## 工作台布局

- 窗口标题栏只承载当前任务和少量窗口操作；其下对话画布使用轻微圆角和 8px 外缘留白，减少贯穿整个窗口的横向分隔线。
- 新任务默认收起右侧工作区，通过标题栏按钮打开；已保存的可见状态、宽度和终端标签原样恢复。
- 空任务保留一行标题、一行说明和紧凑的任务建议，不使用大图标、英文标语和编号卡片。聊天正文与输入框保持同一内容宽度和中线。
- 设置页继续使用通顶双栏，紧凑导航与居中的内容列分离；外观页与其他设置分类使用同一最大宽度。

## 输入区引用与 Agent 命令

- 输入区的「＋」和独立词首 `@` 打开项目文件 / 文件夹列表。当前目录内可搜索，输入 `@src/` 或进入目录继续浏览；Enter 进入文件夹，Tab 引用文件夹，也可通过「引用此文件夹」添加。
- 引用以可移除的标签展示，最多 20 项；发送时附上项目相对路径，Agent 在所属主机按需读取，不上传或复制文件内容。切换主机 / 项目清除引用，发送失败保留草稿和引用。
- 「＋」菜单底部提供工作区外引用：本机可选择文件、选择文件夹或输入绝对路径；远程仅提供「引用远程路径」，由当前远程主机校验路径。项目内路径保持相对路径，外部路径显示规范化绝对路径。引用不扩大 Agent 权限、不自动同步本机文件到远程。取消、无效路径和过期选择不添加引用。
- 输入首位 `/` 从当前项目所属主机的当前 Agent 获取原生命令列表及参数提示；展示 CLI 内置、项目和用户命令，菜单不混入桌面应用操作。选择命令只填写草稿，用户补充参数并发送后，原文经正常任务链路交给 Agent。
- 菜单支持 ↑↓、Enter / Tab、Escape、鼠标和中文输入法；选择菜单项不发送任务。浮层与输入框等宽，列表独立滚动，保持中性焦点背景。加载失败显示原因及重试按钮。
- 斜杠命令不能混入文件引用，以免引用路径改变原生命令参数。未实现的 Agent、缺少命令发现能力的 CLI 和不支持的命令明确报错。

- 斜杠菜单使用紧凑双列：命令名与说明统一对齐，主标题优先使用 Agent 展示名称，其次使用常用命令中文名、Skill 说明中的短标题或格式化名称；原始 `/命令` 作为下方的次要标识，不重复绘制斜杠图标。长说明单行省略并提供完整悬停提示；快捷键提示放在底部，菜单高度上限 320px。

- 输入框占位提示使用很浅的弱化灰色，与实际输入区分；仅混合占位色与输入区底色，不影响正文或其他表单。输入正文行高为 1.5，空白输入区按一行起始，随内容和宽度变化自动增高，最高 200px 后内部滚动。

- 目录搜索使用菜单内的 36px 轻量搜索行，配 16px 搜索图标和中性透明底；内部输入显式清除原生背景、边框和阴影，聚焦时不增加描边。

## Agent 权限

输入框上方左侧为项目选择，右侧显示当前 Agent 名称。输入框内部左侧为添加引用与权限，右侧为模型和发送；不显示「新会话」状态文字。权限与模型控件统一为 32px 高度并垂直居中，权限触发器不继承表单的顶部间距。
权限入口显示盾牌和当前权限模式。菜单沿用公共 Select，展示每项的易读名称与说明；
完全访问使用警示色，选中项保留勾选。默认「跟随 Agent」，不替换为某个推测的档位。
选项由执行主机的 Agent 适配器提供，界面不硬编码 Claude 规则；未知或加载失败时允许恢复跟随
Agent，并提供重试，不自动降级或替用户切换权限。权限按主机 / Agent 记住，新任务恢复，
已有会话使用自身的权限；运行中、断线和归档时禁用切换，选择对下次发送生效。

## 输入区粘贴

- 普通文本插入光标选区；超过 8,000 字符或 200 行时转成 App 管理的 UTF-8 `.txt` 附件，不占满输入框。
- 图片、视频、文件和粘贴文本使用各自图标与类型标签；正文显示原文件名，悬停保留完整引用路径。媒体按原文件保存，不自动转码。
- 剪贴板文件优先于同一次复制携带的缩略图和文件名文本。批量附件保存成功后一次添加；错误保留原草稿和剪贴板内容，避免部分结果误发送。
- 保存与远程传输时显示状态并禁用发送；切换项目、主机或会话后忽略迟到结果。本机附件在本机暂存，远程任务在传输成功后使用远程路径。已有权限设置保持不变。
- 单文件 64 MiB，合计最多 20 个引用；超限直接说明原因。粘贴本机目录只添加路径引用，远程任务提示先传输目录。

## 连续性、模态与阅读

- 会话草稿按主机和会话保留，新任务有独立草稿；仅保存在本次 App 运行的内存中。引用按主机、项目隔离。成功只清除那一版已提交草稿，失败或迟到响应不得清空后来写入的内容。欢迎建议仅在输入为空时显示。
- Provider 表单离开设置后保留在内存中，包括尚未保存的凭据；取消明确丢弃，不写入 WebView 存储。保存按钮靠右，无修改时禁用并显示已保存。
- 所有弹窗复用 Modal：背景 inert，Tab 在当前层内循环，关闭恢复触发点。Select 浮层属于所在弹窗。Escape 逐层关闭，后台新建任务快捷键在弹窗期间暂停。
- 对话普通文字允许长标识符换行，代码与表格仅局部横向滚动，代码块正文 13px。执行过程不展示回复复制入口；最终答复底部保留纯图标复制及成功反馈，代码块保留复制。完成的 turn 默认折叠过程，只展示最后答复，用时摘要右侧使用细线展开箭头，可展开查看中间消息与工具记录；模型/Provider 启动提示不进入正文展示；执行中、等待审批、失败和中断保持过程可见。向上回看时停止跟随并显示“回到最新”，新输出到达时更新提示。
- 输入区按自身宽度简化辅助信息：先省略思考档位，极窄时仅显示权限图标与箭头；模型名和主要操作优先。完整选项仍在菜单中。工作区外引用合并为次级入口。
- 审批使用中性面板、柔和边框和大圆角，类型图标与标题为次要文字；正文以确认问句说明动作，内容预览弱化嵌套背景，右下角使用“拒绝 / 允许一次”胶囊按钮。明确工具 ID 对应的工具调用与审批合并展示，路径与内容预览只出现一次，完整参数默认收起，操作按钮紧跟内容。处理后收成可展开的一行摘要，区分允许与执行完成、失败，保留工具结果；无明确 ID 不猜测并行工具对应关系。
- 失败与状态待确认保留侧栏图标，读取不清除。连接状态分别赋色。终端配置浅深 ANSI 16 色与最低文字对比度，换主题不重建终端、不重放输入。
- 改动视图按未暂存、已暂存、未跟踪分组，列表与单文件预览均限定当前项目。加载和错误保留返回；输出有界，截断时提示，统计仅代表显示内容。
