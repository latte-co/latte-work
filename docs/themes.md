# 导入与复制主题

设置 → 外观 → 主题预设前的「导入 / 复制主题」是唯一入口。

- **复制主题**：将完整外观配置复制到剪贴板。粘贴到纯文本编辑器，保存为 UTF-8 编码的 `.json` 文件，即可分享或备份。
- **导入**：选择一个 JSON 文件，校验通过后立即应用并保存。取消选择不修改任何配置；文件读取失败、格式错误或超过 32 KiB 都不会覆盖现有主题。
- 导入和复制都包含 **浅色、深色两套配置和主题模式**，与当前正在编辑哪一套主题无关。文件只含外观，不含项目、聊天、Agent 权限或凭据。

可直接导入的完整示例：[默认亮色与黑色主题](themes/latte-default.json)。

## JSON 格式

所有下列字段均必填。JSON 不支持注释，字段名区分大小写。

| 顶层字段 | 内容 |
| --- | --- |
| `version` | 数字 `1`，配置格式版本 |
| `mode` | `"system"` 跟随系统、`"light"` 固定浅色、`"dark"` 固定深色 |
| `light` | 浅色主题配置对象 |
| `dark` | 深色主题配置对象 |

`light` 和 `dark` 使用相同字段：

| 字段 | 含义与允许值 |
| --- | --- |
| `accent` | 强调色，六位十六进制颜色，如 `"#2563EB"` |
| `background` | 背景色，如 `"#111111"` |
| `foreground` | 正文前景色，如 `"#EEEEEE"` |
| `contrast` | 面板层次对比度，数字 `0` 至 `100` |
| `translucentSidebar` | 应用内半透明侧栏，布尔值 `true` 或 `false` |
| `uiFont` | UI 字体：`"system"`、`"sans"`、`"serif"`、`"mono"` |
| `contentFont` | 内容字体：上述四种，或 `"inherit"` 跟随 UI 字体 |
| `codeFont` | 代码字体：`"system"`、`"menlo"`、`"consolas"` |
| `uiWeight` | UI 字重：字符串 `"400"`、`"500"`、`"600"` |
| `contentWeight` | 内容字重：同上 |
| `codeWeight` | 代码字重：同上 |

不支持 CSS、字体文件路径或脚本。未知字段会被忽略，不执行任何内容。预设名称不存入 JSON，界面根据导入的颜色识别预设，否则显示「自定义」。
