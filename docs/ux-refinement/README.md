## 验证

2026-09-29 最终 `make ci` 通过：48 项 Rust 单元测试、113 项前端测试、24 项最终二进制 E2E，以及格式、Clippy（拒绝 warning）、类型、Web 构建和 Rust 文档检查。自动回归覆盖草稿/引用隔离、首次发送及迟到响应、模态/嵌套焦点、审批关联、过期历史、文件错误返回、改动分组/范围/路径、ANSI 对比度、Provider 草稿与保存。

共享组件在浏览器中核对了 Latte 浅色、Latte 深色与 Material 深色。运行态停止按钮实测分别为 `rgb(228, 228, 228)`、`rgb(66, 66, 66)`、`rgb(82, 91, 96)`；540px 与 280px 输入区没有横向溢出；长标识符不撑宽正文、代码为 13px，复制有成功反馈。审批完成后的标题和图标保持中性色。

原生测试包使用独立 bundle identifier、状态目录及 deterministic Claude fixture，避免影响用户正在运行的应用。初始测试包已启动，最终源码重新构建原生 app 成功；但 Mac 锁屏导致原生自动化无法点击或输入，最终实机键盘、焦点、拖动与完整任务路径回归未完成。浏览器组件检查和 fixture E2E 不等于原生交互、真实 Provider 或 SSH 链路验证；不自动重放用户请求，不修改原有安装包、凭据或守护进程。

兼容性：结构化改动需要同版本 Server。旧 `diff` 请求保留；旧审批历史缺少 tool_use_id 时不猜测并行工具对应关系。草稿保留范围为本次应用运行，关闭应用后不会写入磁盘。

## Turn 展示调整

按用户请求分组。成功完成后，中间回复、工具调用和已处理审批合并进默认关闭的“查看执行过程”；最后一段答复留在外面。运行中、待审批、失败、中断、状态未知、缺少最终答复或不完整历史保留原过程，不把工具前的进度文字误作最终答复。执行过程不附带“复制回复”；最终答复恢复纯图标复制，代码块复制保留。模型与 Provider 启动提示不再进入正文；过程入口改为用时摘要与右侧细线箭头。
